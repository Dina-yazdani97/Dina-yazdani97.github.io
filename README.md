# وب‌سایت شخصی و رزومه علمی دینا یزدانی (Dina Yazdani)

یک وب‌سایت مدرن آکادمیک و پورتفولیو برای **دینا یزدانی** (پژوهشگر اقلیم‌شناسی، مدل‌سازی سیستم‌های زمین و یادگیری ماشین)، ساخته شده با **Astro**، **Keystatic CMS** و **Tailwind CSS**.

---

## 🔒 امنیت و ورود به پنل مدیریت (CMS Portal)

برای حفظ محرمانگی و امنیت، **هیچ لینکی به CMS در صفحه اصلی وب‌سایت وجود ندارد**. 

دسترسی به پنل مدیریت Keystatic از طریق درگاه احراز هویت امن و محافظت‌شده انجام می‌شود:
- **آدرس ورود به پنل مدیریت**: `http://localhost:4321/admin/login` (یا مستقیماً با رفتن به `/keystatic`)
- **نام کاربری پیش‌فرض**: `admin`
- **رمز عبور پیش‌فرض**: `dina2026!#climate`

> [!TIP]
> برای تغییر نام کاربری یا رمز عبور، کافیست مقادیر `ADMIN_USERNAME` و `ADMIN_PASSWORD` را در فایل [`.env`](file:///c:/Users/Emad/Documents/projects/dina-website/.env) به مقدار دلخواه تغییر دهید.

- نشست ورود با کوکی رمزشده `HttpOnly` ایمن شده و دارای اعتبار ۷ روزه است.
- برای خروج از حساب کاربری نیز آدرس `/admin/logout` در نظر گرفته شده است.

## 🌟 ویژگی‌های کلیدی

1. **پنل مدیریت بصری Keystatic (`/keystatic`)**:
   - بدون نیاز به کدنویسی، کارفرما می‌تواند تمام بخش‌های رزومه را شامل مقالات، سوابق کاری و تحصیلی، جوایز، دوره‌ها و مهارت‌ها کم، زیاد یا ویرایش کند.
   - تغییرات مستقیماً در قالب فایل‌های تمیز و ساختاریافته JSON در مسیر `src/content/` ذخیره می‌شوند.

2. **طراحی مدرن با تم تاریک و روشن (Dark & Light Mode)**:
   - سوییچ سریع میان تم دارک و لایت با حفظ خودکار در `localStorage` و پشتیبانی از تم سیستم‌عامل کاربر.
   - پالت رنگی علمی متناسب با علوم اقلیمی (Emerald, Teal, Cyan و Zinc).

3. **دسته‌بندی و محتوای کامل رزومه**:
   - **پروفایل و بیوگرافی (Profile & Bio)**: شامل اطلاعات تماس، وضعیت تحصیلی، زبان‌ها و لینک‌های علمی (Google Scholar, ORCID, ResearchGate, GitHub, LinkedIn).
   - **حوزه‌های پژوهشی (Research Interests)**: بررسی پروژه‌های DAMIP, CMIP6، مدل‌های یادگیری ماشین در اقلیم، رویدادهای حدی و سنجش از دور.
   - **مقالات و تولیدات علمی (Publications)**: با فیلتر لحظه‌ای (Research Articles, Technical Reports, Under Review)، لینک DOI و دکمه کپی استاندارد استناد (Citation Copy).
   - **سوابق کاری و دستیاری پژوهشی (Experiences & Collaborations)**: همکاری با مؤسسه فناوری کارلسروهه (Karlsruhe Institute)، دانشگاه فردوسی مشهد، کارآموزی یادگیری ماشین در پارک علم و فناوری (Apex Hope)، تدریس و منتورینگ.
   - **تحصیلات و افتخارات (Education & Awards)**: کارشناسی ارشد اقلیم‌شناسی (معدل ۱۸.۴۲ و رتبه اول)، کارشناسی جغرافیا (معدل ۱۹.۵۹ و رتبه اول در میان ۸۱ دانشجو) و رتبه اول کشوری اریگامی ماژولار.
   - **خدمات تخصصی و بین‌المللی (Professional Service)**: داور تخصصی IPCC AR7 (گروه کاری ۱) و تسهیل‌گر کارگاه‌های CMIP7.
   - **ماتریس مهارت‌ها (Skills Matrix)**: تفکیک‌شده در پایتون، R، ابزارهای اقلیمی (CDO, NCO, NetCDF)، سنجش از دور (GEE, ArcGIS, terra, sf) و لینوکس LPIC-1.
   - **گواهی‌ها و دوره‌های تخصصی (Certificates)**: دوره‌های ECMWF، سرویس‌های ماهواره‌ای Copernicus WEkEO، دانشگاه سازمان ملل و آکادمی سنجش از دور.
   - **فعالیت‌های اجتماعی و بین‌رشته‌ای (Outreach & Origami)**: تدریس اریگامی، کاربرد اریگامی در ساختارهای تلسکوپ فضایی جیمز وب (JWST) و تدریس نجوم در آسمان‌نما.
   - **خروجی چاپی و PDF (Printable CV)**: با کلیک روی دکمه «Print CV» یا فشردن `Ctrl + P`، وب‌سایت با استایل اختصاصی پرینت تبدیل به یک رزومه PDF می‌شود.

## 🚀 راهنمای راه‌اندازی و اجرا

### ۱. اجرای سرور توسعه (Development):
```bash
npm run dev
```
سپس در مرورگر خود باز کنید:
- مشاهده سایت: [http://localhost:4321](http://localhost:4321)
- ورود به پنل مدیریت: [http://localhost:4321/admin/login](http://localhost:4321/admin/login)

### ۲. ساخت نسخه نهایی (Production Build):
```bash
npm run build
```

### ۳. پیش‌نمایش نسخه بیلد شده:
```bash
npm run preview
```
